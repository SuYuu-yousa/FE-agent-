

### 4. 手写 bind（面试官最爱的“硬菜”，加 `new` 处理）

以下是**大厂标准满分答案**，注释全给你标好了：

```javascript
Function.prototype.myBind = function(context, ...bindArgs) {
  // 1. 保存原函数（this 指向调用 myBind 的函数）
  const fn = this;
  
  // 2. 返回新函数（绑定了 this）
  function boundFn(...callArgs) {
    // 关键：如果 this 是 boundFn 的实例（说明被 new 调用了），就用 this 作为 context
    // 否则就用传入的 context（显式绑定）
    const finalContext = this instanceof boundFn ? this : context;
    return fn.apply(finalContext, [...bindArgs, ...callArgs]);
  }
  
  // 3. 让新函数继承原函数的原型（处理 new 情况）
  boundFn.prototype = Object.create(fn.prototype);
  
  return boundFn;
};
```

**生产调用对比**：
```javascript
const obj = { name: '张三' };
function greet(age) { console.log(this.name, age); }

const bound = greet.myBind(obj, 18);
bound();          // '张三' 18
new bound();      // undefined 18（new 时 this 指向新实例，原 this 被覆盖，完美符合 new 优先级）
```
