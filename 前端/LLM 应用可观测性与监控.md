# LLM 应用可观测性与监控

> 前端 Agent 岗特有：普通前端监控三块（错误/性能/行为）之外，LLM 应用还要监控 token/成本/延迟。已给大纲，自己填。

## 一、为什么 LLM 应用监控不一样
> 要写：多了一类指标——token 用量、成本、首字延迟 TTFT、流式速率；出错方式也不同（超时/限流/幻觉/空响应）。

## 二、关键指标 ⭐
> 要写：TTFT（首 token 延迟）、流式速率（tokens/s）、总 token 用量与成本、完整响应耗时、错误率。

## 三、多步 trace 链路 ⭐
> 要写：一次 Agent 调用可能是「思考→调工具→再思考→回答」多步，要能追踪每一步（span），定位卡在哪。

## 四、AI 错误处理
> 要写：超时（timeout）、限流（429/rate limit）、空响应、幻觉——前端怎么兜底和重试。

## 五、监控体系扩展
> 要写：采集→上报→分析→告警 如何从普通前端扩展到 LLM 应用；Sentry 集成 LLM 场景。

## 六、结合 Agent
> 要写：给一个「AI 对话助手」设计监控：埋哪些点、看什么指标、怎么定位问题。
